Current release policy

Paid integration licensing is deferred. The earlier proposal to charge for use in paid services is not an active policy. These packages are distributed under their included MIT licenses; no Barocss license key, billing account, or entitlement check is required.

Retain the copyright and permission notice as required by the included LICENSE. The license text also defines the warranty and liability terms. No paid support service is part of this release.

Host SDKs and bundled assets

Host editor SDKs retain their own licenses. The Barocss adapter license does not replace the licenses of TinyMCE, CKEditor, WordPress, or any other host dependency. Host SDKs remain external dependencies of the individual npm plugins.

The core includes a separate KaTeX font license at src/fonts/LICENSE-KaTeX.txt. Keep that notice with the bundled fonts.

See host support for host setup and release preparation for package verification.
